# Site-to-App

Turns any website into a minimal Mac app of its own, with no title bar.

Made with [Lamp](https://lamp.dev), a Mac app that builds apps from a description and changes them as you ask.

## Remix it with Lamp

With Lamp, choose File → Open from GitHub… and paste this repository's address (`https://github.com/lampdotdev/sitetoapp`): you get this exact wish, yours to change by asking, with the credits below kept. Don't have Lamp? [Get it](https://lamp.dev).

## Build it yourself

With Apple's Command Line Tools installed (`xcode-select --install`):

```bash
./build.sh
```

The AI inside the app, and anything it does with other apps or devices, goes through Lamp, so those need Lamp open on the same Mac.

Remixed from [Site-to-App](https://github.com/lampdotdev/sitetoapp) (a Lamp starter).
